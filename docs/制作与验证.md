# 制作与验证

> 文档导航：[README](../README.md) · [原理与架构](原理与架构.md) · [虚拟机迁移与恢复](虚拟机迁移与恢复.md)

本页面向需要从源码构建、运行自检或复核发布状态的维护者，对应 **v1.3.1**。普通下载用户请直接阅读 [README](../README.md) 的下载与使用说明。

## 构建环境

- Windows x64。
- .NET Framework 4.8。
- 系统自带的 C# 编译器。
- 源码中的 `lib/NAudio.dll`（NAudio 1.10）。
- VB-CABLE 不是构建依赖；只有实际测试“播放给 FIF”时才需要单独安装。

NAudio 1.10 的许可为 Microsoft Public License (Ms-PL)，详细来源与许可文本见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

## 从源码构建

在仓库根目录打开 PowerShell，运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

`-NoProfile` 避免当前用户的 PowerShell 配置文件干扰构建；`-ExecutionPolicy Bypass` 只作用于本次 `powershell.exe` 进程，不修改系统或用户的全局执行策略。构建结果位于 `bin\`，主程序为 `bin\FifFloat.exe`。

## 离线自检

```powershell
.\bin\FifFloat.exe --self-test .\self-test.json
```

自检使用程序生成的合成音频，不联网、不安装驱动、不采集真实麦克风，也不访问 FIF 网页。它会在报告所在目录创建隔离的测试数据，主要覆盖：

- 生成并校验 48 kHz/16 bit/单声道 WAV。
- 导入副本、时长读取和重启恢复。
- 不支持格式的拒绝与当前录音保护。
- 列表持久化、改名、移出、删除、默认编号补齐和自定义名称保留。
- 没有 CABLE 时拒绝向默认扬声器回退。

输出报告中的 `success` 为 `true` 才表示自检通过。自检会写入测试目录和 JSON 报告，请放在可写的临时目录，不要把真实录音目录作为报告输出位置。自检通过只说明这些离线检查通过，**不能替代**真实麦克风、实体扬声器、浏览器麦克风权限、VB-CABLE 路由或 FIF 页面评分流程的验收。

## CABLE 选择检查

需要完整安装 VB-CABLE 时，可使用维护者检查：

```powershell
.\bin\FifFloat.exe --probe-selection .\probe-selection.json
```

该命令会生成合成音，通过 `CABLE Input` 播放并从 `CABLE Output` 捕获，验证点选条目的播放是否对应正确，不打开实体麦克风或实体扬声器，也不访问 FIF 网页。

这不是离线自检：没有 CABLE 或只有一半设备时不要运行。普通用户不需要执行。本说明不将这条检查表述为已在当前环境通过；只有实际运行并得到成功报告，才能记录为该项通过。

## 验证现状

- 根据用户反馈，v1.3.0 程序已在一台 Windows 虚拟机中安装成功。该反馈仅覆盖安装环节，不代表维护者在该虚拟机中完成了 FIF 收音或评分测试。
- 尚未验证：虚拟机中的实际 FIF 网页收音、回放质量、评分流程，以及真实麦克风/扬声器、浏览器版本与权限、虚拟机音频重定向等环境差异。
- 源码中的按钮文案、WAV 导入限制和自检入口可作为文档事实依据，但代码检查与离线自检都不是实际音频链路验收。

迁移到新虚拟机或新电脑后，请按 [虚拟机迁移与恢复](虚拟机迁移与恢复.md) 使用不含隐私内容的短 WAV 做一次完整验收。验收记录和自检报告只保存在本机，不要把个人录音、设备快照、绝对路径或浏览器资料加入仓库。
