# 虚拟机迁移与恢复

> 文档导航：[README](../README.md) · [原理与架构](原理与架构.md) · [制作与验证](制作与验证.md)

本页说明如何把 **v1.3.0** 迁移到 Windows 虚拟机、在虚拟机内验收声音链路，以及不再使用时恢复宿主机。普通使用不需要迁移；需要重新安装或清理时也可参考本页。

## 迁移前准备

- 虚拟机目标系统为 Windows x64，并已安装 .NET Framework 4.8。
- 在虚拟机设置中启用音频设备，确认宿主机本身有可用的播放端。
- 普通下载用户从 [GitHub Releases](https://github.com/zhangenzhi233/fif-audio-float/releases/latest) 取得发行包；需要从源码构建时，按 [制作与验证](制作与验证.md) 操作。
- 只迁移程序时，带上发行包解压后的程序文件即可；`录音/` 中含录音和列表元数据，如确需迁移自己的录音，请单独备份和检查，不要放进公开仓库。
- 不要在程序仓库中保存浏览器资料、测试报告、设备快照或宿主机的驱动安装包。
- 程序日常运行无需管理员权限，但要放在虚拟机内当前用户可写的目录。VB-CABLE 自身的安装程序可能请求管理员权限。

## 在虚拟机中安装

1. 安装或确认 .NET Framework 4.8。
2. 解压 FIF Audio Float 发行包到普通可写文件夹，运行 `FifFloat.exe`。
3. 需要网页虚拟麦克风时，从 [VB-Audio 官方页面](https://vb-audio.com/Cable/) 在**虚拟机内部**单独安装 VB-CABLE，并按官方说明重启。不要从宿主机或本项目复制驱动文件。
4. 打开 Windows 声音设置，确认虚拟声卡同时提供 `CABLE Input`（播放端）和 `CABLE Output`（录音端）。
5. 保持真实耳机或扬声器为 Windows 默认播放设备，**不要把 `CABLE Input` 设为默认扬声器**。
6. 打开小窗的“设备与设置”，点“刷新”确认检测到虚拟声卡。如果没有 CABLE，仍可录音和本地试听，但不能“播放给 FIF”。
7. 在 Edge 中打开 FIF 页面，点击小窗的“复制麦克风设置地址”。该按钮只复制 `edge://settings/content/microphone`；请手动粘贴到地址栏并按 Enter，再把网页麦克风选为 `CABLE Output (VB-Audio Virtual Cable)`。
8. 如网页出现麦克风权限提示，请允许；选择设备后刷新页面再开始录音。

工具“播放给 FIF”固定送往 `CABLE Input`，网页麦克风选择 `CABLE Output`，两者不要选反。

## 在虚拟机中验收

安装完成不等于声音链路已经通过。建议先使用一段**不含个人内容的短 WAV**，在虚拟机内逐项确认：

1. **本地试听**：选择真实耳机或扬声器作为“本地试听输出”，点“试听”，确认能听到声音且不是从虚拟通道送出。
2. **网页收音**：在 FIF 网页开始录音，确认网页麦克风为 `CABLE Output`；回到小窗点目标行的“播放”，观察网页是否出现电平或波形。播放结束后，再在网页结束录音并回放。
3. **逐条选择**：列表有多条时，分别点不同条目的“播放”，确认每次只送入所选那一条，不会自动连播，也不会自动切换网页题目。
4. **提交与评分**：由你在网页完成。本工具不会结束网页录音、提交作业或解释评分；不要用“安装成功”代替这些实际页面操作。

验收用的录音和报告只保存在本机。不要把他人的录音、账户信息、绝对路径、设备清单或测试日志提交到仓库。

## 虚拟机音频排查

- **虚拟机里没有声音设备**：检查虚拟机音频适配器是否启用、宿主机播放端是否可用，必要时关闭远程音频重定向后重启虚拟机。进入系统后重新检查设备。
- **看不到 CABLE 设备**：在虚拟机内部按官方说明安装 VB-CABLE 并重启，再点小窗“刷新”。宿主机安装的虚拟声卡不一定会自动出现在虚拟机中。
- **只有一半 CABLE 设备**：确认 `CABLE Input` 和 `CABLE Output` 都存在；缺失时按官方说明重新安装或重启，不要从别人机器复制驱动文件。
- **内录没有电平**：确认浏览器实际使用的 Windows 输出端，就是工具“录电脑声音”选中的设备；切换耳机或音频重定向后要重新选择并刷新。详见 README 的[故障排查](../README.md#故障排查)。
- **网页没有收到声音**：确认网页麦克风是 `CABLE Output`，不是 `CABLE Input`；先在网页开始录音，再从小窗播放对应条目。
- **默认扬声器被改成了虚拟设备**：在 Windows 声音设置中改回真实耳机或扬声器。虚拟机内单独选择的设备不会自动修复宿主机的设置。

宿主机上通过的音频配置，不能直接作为虚拟机验收结论；每次更换虚拟机、远程桌面设置或音频直通方式后，都要在虚拟机内重新选择和测试。

## 恢复宿主机

如果需要撤销虚拟声卡配置或清理迁移环境，请按以下顺序手动处理：

1. 在 FIF 网页和 Edge 中把麦克风改回实体麦克风或其他实际使用的设备。
2. 在 Windows 声音设置中确认默认播放设备是真实耳机或扬声器，而不是 `CABLE Input`。
3. 如不再需要 VB-CABLE，按 [VB-Audio 官方页面](https://vb-audio.com/Cable/) 的说明卸载，必要时重启。
4. 如需保留录音，先备份程序旁的 `录音/` 目录；删除程序前确认里面的 WAV 和 `录音列表.json` 不再需要。
5. 删除不再需要的程序目录、测试 WAV 和报告。删除整个程序目录会同时删除旁边的录音数据，因此不要直接删除未备份的目录。

删除本工具本身不会自动卸载 VB-CABLE，也不会自动改回浏览器、网页或 Windows 的音频设置。虚拟声卡的安装、卸载和默认设备变更都需要使用者手动确认。

## 验证现状

根据用户反馈，v1.3.0 已在一台 Windows 虚拟机中安装成功；该反馈仅覆盖安装环节。虚拟机中的实际 FIF 网页收音、回放质量、评分流程，以及不同虚拟机的音频重定向和设备直通差异，尚未由项目文档验证。

请以本页的验收步骤和实际页面结果为准，不要仅凭安装成功或源码自检推断完整链路已通过。如果验收失败，先按“虚拟机音频排查”核对设备，再记录可复现的错误信息；不要提交包含个人音频或设备信息的报告。
