# 原理与架构

## 目标

该工具在本地准备和管理多条 WAV 录音。用户从列表中选择一条，再点击该行“播放”，程序将该条声音写入虚拟播放端；网页将相应虚拟录音端作为麦克风输入。每次操作只处理用户点选的一条，不含题目识别、自动顺序播放或网页自动化。

```text
浏览器或其他应用的声音
          │（选择的 Windows 输出端）
          ▼
   本工具的电脑声音录制 ──► WAV + 本地列表元数据
                                  │
                                  ▼（用户点选某一条）
                          CABLE Input
                                  │ VB-CABLE 内部路由
                                  ▼
                          CABLE Output ──► 浏览器网页麦克风
```

“录电脑声音”使用 Windows 输出端的 loopback 捕获，因此会录到该端点的混音；浏览器、提示音或其他同时使用该端点的应用都可能进入录音。耳机可避免扬声器外放，但不会将捕获范围缩小到某一标签页。

## 模块

| 文件 | 职责 |
| --- | --- |
| `src/FloatingForm.cs` | WinForms 置顶窗口、设备选择、录音列表和用户交互 |
| `src/AudioEngine.cs` | 麦克风/loopback 捕获、WAV 校验、虚拟端播放 |
| `src/RecordingLibrary.cs` | 本地录音元数据、改名、移出、删除和连续编号 |
| `src/SystemAudio.cs` | 读取或恢复 Windows 默认播放端的辅助逻辑 |
| `src/Program.cs` | 程序入口、诊断和隔离自检 |

## 数据与删除语义

完整录音为 WAV；录制期间使用 `.wav.part`，正常结束才写为完整 WAV。列表索引只保存相对文件名、显示名与移出状态，名称修改不会重命名 WAV。

- **移出列表**：只从元数据隐藏，WAV 仍保留在录音目录。
- **删除**：直接删除该 WAV，不创建副本、不移动到回收站；若删除或索引保存失败，程序应保留原文件和可恢复的列表状态。
- 默认名称会补齐连续的“录音 N”；自定义名称保持不变。

## 安全边界

工具在本地读写录音目录，不上传音频，也不读取网页账户。它不会点击网页开始/结束录音、提交作业或解释 AI 评分。VB-CABLE 是独立的系统驱动，必须由使用者从官方渠道安装；本源码不会下载或调用驱动安装程序。
